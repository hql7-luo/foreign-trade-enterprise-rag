# Fully synthetic Northstar Trading data

This file contains fully synthetic data created for portfolio demonstration purposes.

Northstar Trading is fictional. Records, identifiers, values, policies, dates, historical terms and simulated compliance references were invented for this independent public edition. They are not anonymized or paraphrased company records.

`source/` is the approved bootstrap corpus. `updates/` contains unapproved review evidence and is never automatically indexed. The product master has ten identities, including two deliberately duplicated SKUs. Empty CSV fields mean unverified, not zero. Catalog amounts are dated reference values, not binding customer quotes. No certificate is valid for regulatory use.
