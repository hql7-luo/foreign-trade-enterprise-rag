# v1.0.0 — Foreign Trade Enterprise RAG

Independent public portfolio edition, with a fresh Git history.

- Configurable multilingual dense embeddings, BM25, Qdrant, RRF and lightweight reranking.
- SQLite source/version metadata, Current Product Master and claim-level evidence citations.
- Pending / approved / rejected / superseded facts, conflict detection and auditable review.
- Employee / Reviewer / Admin roles, generated local accounts and persistent session digests.
- Controlled ingestion, background reindex jobs, privacy checks and bounded evidence access.
- React + FastAPI interface, accessibility checks, Docker/CI configuration and operator tooling.
- Newly authored synthetic evaluations with frozen first-run artifacts and documented failures.
- Fictional Northstar data and a real, silent browser demo of approval changing future answers.

**This public release contains synthetic demonstration data only.** No private records,
private-derived labels, historical private Git objects or real-company benchmark scores are
included. The internal holdback is not independently human-authored blind validation.

The default reproducible demo uses an offline hash embedding fallback, not a neural model;
multilingual MiniLM is optional. Answer generation is local extractive composition.
No paid cloud deployment is running. Docker configuration is supplied; host/runtime validation
status and known limitations are documented in the public release report.
