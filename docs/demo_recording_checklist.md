# Recording checklist

- Fresh fictional source manifest; base product MOQ is 144, not a previously approved 180.
- Credentials generated locally; terminal hidden; isolated browser profile; no notifications.
- 1920×1080 viewport, readable zoom, silent capture, 2–3 minute target.
- Employee: exact product, citation drawer, unverified lead time, historical terms.
- Admin: stage only the packaged update; confirm no authoritative fact changed yet.
- Reviewer: compare values, inspect source, enter a meaningful synthetic review note, approve.
- Product Master: inspect MOQ history, retaining the old value as historical.
- Admin: wait for the reindex job to complete; cut only uninformative waiting time if needed.
- Employee: ask again; verify 180 units in both answer and cited approved-change excerpt.
- Verify full decoding, duration/resolution, all scenes, no visible credentials or personal paths.
- If a new take is needed, preserve the old runtime and start a new isolated runtime; do not
  delete a broad directory or reuse a private company workspace.
- If the backend is unavailable, check `/ready`; if the final citation is stale, finish the
  controlled reindex rather than faking the result.
